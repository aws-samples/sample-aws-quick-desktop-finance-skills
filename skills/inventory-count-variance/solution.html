存货盘点 · 核心判据

账实交叉 + 损耗容差 + 差异守恒

判据规则结果
账实交叉按 SKU+仓库；账有实无/实有账无/盘盈/盘亏异常 / 差异
单位一致账实单位相同，数量才可比异常
合理损耗差异率 ≤ 类别损耗率 → 正常损耗；超出 → 异常差异
金额分级差异金额 ≥ 重大差异阈值 → 重大差异异常/差异
边界账存/实盘 ≥ 0；单价 > 0异常
多仓完整性同一 SKU 所有账存仓位都要盘点漏盘
差异守恒：净差异 = 盘盈 − 盘亏；另列盘盈毛额、盘亏毛额，防止双向差异在净额里相互抵消。

存货盘点 · 判据边界

账实对上了，也不等于存货价值一定真实

盲区为什么抓不到处置可闭合性
自然损耗误判账多实少但在损耗率内类别损耗率容差，已在脚本中实现🟢 已闭合
净额掩盖盘盈盘亏相互抵消分向毛额，已在脚本中实现🟢 已闭合
账实同错盘点也按账面数走过场突击盘点、监盘、抽盘复核🟡 需外部锚点
存货跌价数量对，但已过期/滞销/减值对接效期、周转率与市场价（跌价准备）🟡 需外部锚点
判据能证明“账实数量相符、差异分清正常与异常”，不能证明“盘点真实、存货没减值”——这些边界已写入 Skill 的判据覆盖声明。

① 逐项留痕

59 个 SKU-仓位各记账存、实盘、差异率、差异金额与判定。

② 基准与指纹

盘点基准日、损耗率、阈值固定；四个输入各记 SHA-256 指纹。

③ 守恒 + 复算

净差异=盘盈−盘亏、分向毛额；本机用同一份 CSV 独立复算，与云端一致。

证据 JSON 同时输出为网页、PDF、Markdown、Excel 四种报告，每一笔盘盈盘亏都能追溯到 SKU、仓库和单价折算。
