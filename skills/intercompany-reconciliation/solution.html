判据规则结果
完整性同一交易号双方各一条，不多不少单边 / 重复 → 异常
对手方对称A 的对手方 = B 的记账实体，反之亦然异常
方向一方应收（+）、一方应付（−）异常
交叉一致A 额 + B 额 = 0差异
类型一致 · 时间性交易类型相同；入账日期差 ≤ 5 天差异
抵消守恒全体净额 = 各交易净额之和，正负分开列示自检
范围完备财务标记 ↔ 工商登记，量化未标记关联方余额需外部来源

关联方往来 · 过程可回溯

每笔差异都能倒查回双方分录

① 逐笔留痕

植错版 122 笔交易各记双方金额、净额、记录数和问题标签。

② 输入指纹

台账、两份关联方清单、客商余额四个输入各记 SHA-256 指纹与行数。

③ 守恒 + 复算

全体净额 = 各交易净额之和；本机用同一份 CSV 独立复算，结果与云端一致。

证据 JSON 同时输出为网页、PDF、Markdown、Excel 四种报告，审计可从任意一笔差异追溯到双方原始分录。
