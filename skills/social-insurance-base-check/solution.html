社保公积金 · 核心判据

基数核定 + 缴费恒等式

判据规则结果
基数核定社保=clamp(工资,社平60%,300%)；公积金=clamp(工资,最低,封顶)不符
基数区间下限 ≤ 基数 ≤ 上限越界
社保基数一致养老/医疗/失业/工伤四险基数相同待核实
费率白名单单位/个人费率 == 规则表不符
缴费恒等式单位缴费 = 基数 × 单位费率；个人同理不符
完整性每人每险种齐全；缴费员工在花名册漏缴 / 花名册外
守恒：按核定基数×规则费率重算应缴，与实缴逐条比对，差异分单位、个人两个方向列示。

社保公积金 · 判据边界

缴费算对了，也不等于基数一定合规

盲区为什么抓不到处置可闭合性
低报基数基数仍在区间内，但低于工资托底按核定工资比对，已在脚本中实现🟢 已闭合
四险基数不一致各险种分别填，口径不统一同员工社保基数一致，已在脚本中实现🟢 已闭合
工资基数本身不实申报工资低于实发工资与工资表、个税申报交叉（#18 薪酬个税）🟡 需外部锚点
社平/费率政策更新参保地社平工资、费率已调整对接当地社保局最新公布口径🟡 需外部锚点
判据能证明“按申报工资核定正确、缴费算对”，不能证明“申报工资就是真实工资”——这些边界已写入 Skill 的判据覆盖声明。
