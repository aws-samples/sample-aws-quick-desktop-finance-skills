# 💰 月末财务对账 Skill

> AWS Quick Desktop 可复用技能 — 从数据采集到报告与分发草稿的端到端财务对账自动化

## 功能概述

一键完成月末财务对账全流程：

- 从 **OneDrive** 拉取 ERP 数据包
- 从 **Outlook 邮箱** 提取银行电子回单（PDF 附件）
- 执行**三维度自动对账**（参考号 + 金额 + 摘要匹配）
- 生成**交互式仪表盘**（6 个 ECharts 图表）
- 生成**对账结果 Excel**（4 个 sheet）
- 生成**报告邮件与通知草稿**（本地文件），由使用者确认后自行分发；本 Skill 不发送任何内容

## 前置条件

### 需要连接的服务

| 连接器 | 用途 | 必需 |
| --- | --- | --- |
| **Microsoft OneDrive** | 拉取 ERP 数据（只读） | ✅ 必需（cloud 模式） |
| **Microsoft Outlook** | 读取银行回单邮件（只读） | ✅ 必需（cloud 模式） |

本 Skill 读取外部邮件和 PDF，因此不使用任何外发或建定时任务的工具（不发邮件、不发 Teams/Slack 消息、不回写 OneDrive、不创建定时任务）。

### OneDrive 目录结构

```
OneDrive/
└── 财务月末数据_202608/
    ├── 财务月末数据包_202608.xlsx    ← ERP 导出数据（5 个 sheet）
    └── 对账结果_202608.xlsx          ← 如需归档，由使用者核对后自行上传（本 Skill 不回写）

```

### Outlook 邮件格式

银行回单邮件标题应包含关键词 **"电子回单通知"**，例如：

```
【中国工商银行】电子回单通知 - 08-14 付款 ¥242,100 → 示例公司30

```

## 使用方法

### 方式一：对话触发

在 Quick Desktop 中直接对话：

```
用户: 开始本月对账
Agent: 好的，我来执行月末对账流程...
       Step 1: 从 OneDrive 下载 ERP 数据... ✅
       Step 2: 从邮箱提取银行回单... ✅ (8 份)
       Step 3: 执行三维度自动对账... ✅ (匹配率 80%，按银行流水计)
       ...

```

### 方式二：定时任务（routine）自动触发（由使用者手动配置）

本 Skill 不会创建定时任务。如需每月最后一个工作日自动执行，由使用者自己配置：

1. 从顶栏打开 **Mission Control**，选择 **Create** 新建 routine
2. 按以下内容配置后开启：
   - Repeats：每月最后一个工作日 09:00
   - Triggers：月末财务对账助手（Agent）
   - Instructions："请执行本月的财务月末对账流程"

定时任务在云端运行，应用关闭或电脑关机也会按时执行；但读本机文件、浏览器自动化、本地代码执行这类步骤要求电脑开机、应用运行并保持连接，否则该步骤不可用。`local` 模式在本机计算，挂定时任务时请保证电脑在线。每次运行同样只生成本地草稿，分发仍由使用者完成。

## 7 步流程说明

| 步骤 | 名称 | 模式 | 工具 |
| --- | --- | --- | --- |
| 1 | 数据采集 | agentic | OneDrive 连接器 |
| 2 | 邮件回单提取 | agentic | Outlook 连接器 + PDF 解析；按 `trusted_senders` 核验发件人 |
| 3 | 数据清洗+自动对账 | deterministic | run_python (pandas + difflib) |
| 4 | 智能分析+可视化 | deterministic | run_python + ECharts |
| 5 | 报告生成 | deterministic | run_python (xlsxwriter) |
| 6 | 生成分发草稿 | deterministic | run_python_with_write（只写本地文件，不发送） |
| 7 | 每月例行运行（可选） | 使用者手动配置 | Mission Control 中的定时任务（routine），本 Skill 不创建 |

## 配置选项

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `onedrive_folder` | `财务月末数据_{YYYYMM}` | OneDrive 数据文件夹名 |
| `erp_filename` | `财务月末数据包_{YYYYMM}.xlsx` | ERP 数据包文件名 |
| `email_search_keyword` | `电子回单通知` | 邮件搜索关键词 |
| `email_search_days` | `31` | 搜索最近 N 天的邮件 |
| `trusted_senders` | `[]` | 受信任的银行回单发件人邮箱清单（完整地址）；清单外的回单列为「未验证来源回单」，不作为对账凭证。提供 PDF 正文时，正文的交易日期、金额与文件名不一致的回单同样不作为凭证；未提供正文的回单无法核对交易日期与金额，同样不作为凭证（列入 `receipt_check.未提供正文`）。默认空清单 = 没有回单能通过核验 |
| `reconciliation_tolerance` | `0.01` | 金额匹配容差（1%） |
| `similarity_threshold` | `0.6` | 摘要匹配相似度阈值 |

## 输出文件

| 文件 | 格式 | 内容 |
| --- | --- | --- |
| 对账结果 Excel | .xlsx | 匹配明细 / 仅ERP / 仅银行 / 汇总统计 |
| 对账仪表盘 | .html | 6 个交互图表 + KPI + 未匹配明细表 |
| 报告邮件草稿 | `对账报告邮件草稿.html` | 对账概况 + 关注事项（不发送） |
| 通知草稿 | `对账通知草稿.md` | 关键指标简报（不发送） |
