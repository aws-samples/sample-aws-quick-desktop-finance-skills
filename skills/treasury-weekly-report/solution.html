🧩 固化为可复用 Skill
这套周报流程不是一次性脚本，而是被写成一个 Skill——一句"资金周报"随时复用
🧭 模型编排（指挥官）
对话触发后，模型负责意图识别与工具编排——决定调用哪些引擎、按什么顺序，但不接触原始交易数据，只看结果摘要。
🔒 沙箱计算（操作员）
五大计算引擎是确定性脚本，在 Python 沙箱内运行，逐笔扫描全部流水（演示数据 50,000 笔）。敏感数据可走本地模式：原始文件留在本机，由本机脚本完成计算，只把结果摘要回传给云端模型。
📦 固化为 SKILL.md
treasury-weekly-report
上层不折旧：目标+5份输入契约+10步流程+16维度输出契约+校验规则（核心IP）。下层可替换：连接器/脚本/路径随平台演进。
一次构建，三种复用：① 对话框一句"资金周报"即时触发　② 使用者在 Mission Control 自行配置每周一定时运行　③ 规则表与上期结果沉淀 Agent Files，形成环比链。这正是 AWS Quick 区别于普通对话工具的核心——把流程固化成资产，让工作流长出记忆和肌肉。
