应付账龄 · 核心判据

先把每笔余额算对，再分组

判据规则结果
主数据供应商已登记；台账账期 = 主数据账期不符
到期日推算到期日 = 发票日期 + 主数据账期，不采信台账不符
已付核实台账已付 = 付款明细合计；未付 = 应付 − 已付不符
付款对象付款的供应商 = 应付单的供应商；不一致的付款不冲减该应付不符
唯一性同一供应商 + 发票日期 + 金额只入账一次；同一张单不重复付款不符
分向列示只对欠款分桶；多付形成的借方余额单列，不抵欠款单列
对总账明细合计 = 总账余额；付款必须对应存在的应付单不符
分桶守恒：各账龄段合计 = 核实后的欠款合计；笔数守恒：每张应付单恰好进入一个账龄段。

应付账龄 · 判据边界

账龄算对了，也不等于欠款一定真实

盲区为什么抓不到处置可闭合性
到期日被改台账到期日推后，逾期藏成未到期按主数据账期独立推算，已在脚本中实现🟢 已闭合
多付抵欠款借方余额与贷方余额相抵分向列示，已在脚本中实现🟢 已闭合
账期主数据本身错主数据账期与合同不符对接采购合同的付款条款🟡 需外部锚点
欠款是否真实台账和总账一致，但供应商不认与供应商对账单核对（#11 供应商对账）🟡 需外部锚点
账龄分析能证明“按我们的账，欠谁多少、欠多久”；要证明“对方也认”，需要接上 #11 供应商对账——这些边界已写入 Skill 的判据覆盖声明。
